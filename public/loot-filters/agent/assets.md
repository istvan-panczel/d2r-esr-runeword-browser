# Bundled sounds and icons

Use only these files: the app's "Download .zip with sounds and icons" puts them in the `sounds` and `icons` folders next to the filter. Other files work only if the user adds them; ask first.

## Sounds (`"sound": "tink.mp3"`)

- `tink.mp3`: Jackpot drops: high runes, ESR runes, legendary materials.
- `tinkLOUD.mp3`: A louder tink for the drops you must never miss.
- `mid.mp3`: Good but common drops: Mal to Gul runes, Socket Donuts, Worldstone Shards.
- `other.mp3`: Notable drops: rare jewels, +All Skills bases, unique jewellery, big gold piles.
- `unique.mp3`: Unique and set items.
- `mythical.mp3`: Mythical uniques, the rarest drops.
- `gong.mp3`: Uber keys, organs and essences; rare crafting reagents.
- `map.mp3`: Tier 2 to 4 maps.
- `t5_map.mp3`: Tier 5 maps.

## Minimap icons (`"icon": { "iconName": "rune", "iconSize": 40 }`, the name without .sprite)

- `goldstar`: Uniques and other valuable drops.
- `star`: Set items.
- `Myth`: Mythical uniques.
- `rune`: Runes.
- `gem`: Jewels.
- `gem2`: Perfect gems and rune crystals.
- `gemP`: Uber keys, organs and essences.
- `charm`: Charms.
- `cube`: Crafting reagents (body parts).
- `redD`: Rare crafting materials.
- `scroll`: Coupons and scrolls.
- `map`: Maps.
- `star_gold`: Unique items; pairs with the Unique preset.
- `crown_gold`: The uniques worth the most; pairs with the Unique preset.
- `star_green`: Set items; pairs with the Set preset.
- `star_purple`: Mythical uniques; pairs with the Mythical unique preset.
- `crown_purple`: The rarest mythical uniques; pairs with the Mythical unique preset.
- `diamond_red`: High runes; pairs with the High rune preset.
- `diamond_orange`: Mid runes; pairs with the Mid rune preset.
- `triangle_orange`: Low runes and other minor drops; matches the Low rune preset (which has no icon itself).
- `cross_red`: Anything rare and valuable without an icon of its own; pairs with the Valuable preset.
- `shield_white`: Runeword bases with the sockets you want; pairs with the Runeword base preset.
- `square_emerald`: Charms worth checking; pairs with the Good charm preset.
- `hexagon_teal`: Jewels; pairs with the Good jewel preset (its teal border).
- `hexagon_yellow`: Rare jewels; pairs with the Good jewel preset (its yellow name).
- `ring_blue`: Rings, amulets and class jewellery; pairs with the Good jewellery preset.
- `skull_purple`: Uber organs and essences; pairs with the Uber key or organ preset.
- `key_purple`: Uber keys; pairs with the Uber key or organ preset.
- `gem_gold`: Perfect gems; pairs with the Perfect gem preset.
- `flame_orange`: Crafting reagents; pairs with the Crafting reagent preset.
- `coin_gold`: Rare reagents and large gold piles; pairs with the Rare reagent (gold plate) preset.
- `scroll_gold`: Ancient Coupons; pairs with the Coupon preset.
- `map_white`: Maps; pairs with the Map preset.
- `circle_grey`: Drops you keep visible but quiet; matches the Muted preset (which has no icon itself).
- `star_white`: Any colour: set the icon tint (it multiplies the colours).
- `diamond_white`: Any colour: set the icon tint (it multiplies the colours).
- `circle_white`: Any colour: set the icon tint (it multiplies the colours).

Icon sizes of 30 to 50 minimap pixels read well. A sound name of the game's sounds.txt also works as "sound" (it follows the game volume; no file needed). The reference does not list them: use one only when the user asks for a game sound, with the exact name the user gives (the app's sound picker lists them).
